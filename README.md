# 张俊杰 · 手机端个人简历

以姓名、岗位、工作经历和项目经验为主的手机端个人简历，支持按需开启三维项目演示，桌面端也可访问。

## 已实现

- 默认呈现轻量静态项目预览；用户点击“启动三维演示”后，才加载 Three.js。
- 三个实时场景按首次选择创建：AI 应用、无限画布、光储充微电网。
- 手势旋转与双指缩放、暂停动画、重置视角、沉浸浏览（兼容不支持 Fullscreen API 的手机）。
- 手机底部导航、项目详情底部弹层、下拉关闭、ESC 关闭与焦点恢复。
- 可拖动的画布节点、可播放/暂停的短视频编辑器动效示意。
- 按已确认内容展示三段工作履历；支持切换查看职责。
- AIMagic 真实网站截图、在线产品入口、简历 PDF 下载、邮件/电话联系和邮箱复制。
- 手机优先响应式布局、本地字体、响应式缩略图、减少动态效果偏好。
- 唯一渲染调度入口，最高 30fps；暂停、项目弹层遮挡、离屏、页面隐藏时停止调度。
- 手机 DPR 最高 1.25，低内存设备为 1；使用简化材质、共享几何与材质缓存。

三维模型是根据项目方向制作的程序化展示模型；首屏微电网模型、画布及编辑器预览为交互示意。微电网项目卡片与详情使用用户提供的真实大屏截图，支持放大查看及打开在线大屏；AIMagic 图片来自公开官网实拍。未添加未确认的用户量、收入或业务成绩。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

默认端口 4173，服务器允许同一局域网设备访问。手机与电脑连接相同 Wi-Fi 后，使用终端显示的 Network 地址。电脑休眠或服务器关闭后，本地预览不可用。

## 构建与部署

```bash
npm run build
npm run preview
```

`dist/` 是可部署的静态网站，上传到 Nginx、Cloudflare Pages、Vercel 等静态托管即可。所有模型、字体、代码和简历都随站点打包；没有必需的外部 API。只在点击 AIMagic 或微电网大屏链接时访问对应外部网站。当前任务仅制作和本地预览，没有发布到公网。

## 修改内容

- `index.html`：首页、项目卡片、联系信息等。
- `src/content.js`：项目详情文案。
- `src/main.js`：工作经历内容、三维按需启动与交互。
- `src/scene.js`：Three.js 三维场景。
- `src/style.css`：手机优先的视觉与适配。
- `public/zhang-junjie-resume.pdf` / `.docx`：下载简历。

字体授权在 `public/fonts-license.txt`；Three.js 与 Vite 依赖及版本见 `package.json` / `package-lock.json`。
